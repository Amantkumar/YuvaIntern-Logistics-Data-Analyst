This report presents the work completed for Week 2 of the Yuva Intern Logistics Data Analyst Internship, focusing on Data Collection, Cleaning, and Preprocessing for Logistics Analysis. The objective of this task was to simulate a practical data preparation pipeline that converts raw logistics records into a consistent dataset suitable for further analysis and machine learning.

The project continues the logistics scenario introduced in Week 1, where shipment-level data is used to study delivery performance, transportation cost, distance, shipment volume, traffic conditions, and delivery delays. Publicly available logistics and supply-chain datasets were reviewed as references for realistic data structures and common data-quality challenges. The working dataset included with the project is clearly treated as an illustrative/simulated dataset.

The preprocessing workflow begins with data inspection to understand the dataset structure, data types, missing values, and duplicate records. Duplicate records were identified and removed to avoid double-counting shipments. Numerical columns were converted to appropriate numeric types, while the delivery date was converted into a proper datetime format. Missing numerical values were handled using median imputation because the median is less sensitive to extreme observations. Categorical fields were standardized to reduce inconsistencies in grouping and analysis.

The report also demonstrates outlier detection using the Interquartile Range (IQR) method. Instead of automatically deleting unusual observations, extreme numerical values are capped at the calculated IQR boundaries so that potentially valid logistics events are retained while reducing their influence. Finally, Min-Max normalization is applied to selected continuous variables, transforming them to a 0–1 scale for downstream analytical and machine-learning workflows.

Python code using pandas, NumPy, and scikit-learn is included to make the preprocessing process reproducible. The final cleaned and preprocessed datasets are prepared for Week 3, where advanced exploratory analysis and visualization will be performed. Overall, this task demonstrates how systematic data quality management supports reliable logistics analytics and better data-driven decision-making.
