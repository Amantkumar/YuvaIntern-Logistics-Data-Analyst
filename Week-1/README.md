### Important note
The CSV is an **illustrative/simulated dataset created for demonstrating the planned Week 1 analytical workflow**. It is not presented as a real company's operational data or as measured business results.

### Scenario
Last-mile delivery performance analysis, focusing on delivery time, on-time performance, transportation cost, distance, shipment volume, traffic, vehicle type, and region.

### Planned techniques
- Data quality checks
- KPI calculation
- Exploratory Data Analysis
- Correlation analysis
- Linear Regression
- K-Means clustering
- Strategic optimization planning

### Run
Place all three files in the same folder and run:

```bash
python YuvaIntern_Week1_Python_Logistics_Analysis.py
```

The script expects the input file to be named `logistics_data.csv`.
